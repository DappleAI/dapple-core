# Conduit Context — Stub Flow

A deliberately trivial flow used by external-api lifecycle tests: one stage,
one step, one nushell task that returns a fixed payload.

## Bindings

This guide defines no value slots. The `stub-task` payload
(`{ echo, constant }`) is asserted by tests, never sent to a model.
