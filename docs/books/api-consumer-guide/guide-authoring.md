# Guide Authoring

Guide authoring -- writing guide directories with markdown directives, `guide.toml`, Fluent localization files, and SUMMARY.md -- is covered in the **[Journey Planner Guide](../journey-planner-guide/guide-directory-structure.md)**. That guide provides complete documentation on directory structure, directive block syntax, Fluent messages, inference profile definitions, and a full walkthrough.

This API Consumer Guide focuses on **programmatic consumption**: how to ingest guides via the [SDK and HTTP API](./ingest-api.md) and query [guide cards and favorites](./guide-cards-and-favorites.md). (Shared content endpoints are [deferred to V2+](./shared-content.md) and not currently available.)
