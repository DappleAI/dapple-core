# Audiences

Find your path through this guide.

Each role that touches billing data has different questions and different tools. A Growth team member tracking conversions needs different queries than a Finance analyst preparing for month-end close. These audience guides help you find the most relevant sections quickly.

Start with the guide that matches your role. Each one explains what data you'll typically work with, which queries are most useful, and where to go deeper when you need more detail.

| Role | Start Here |
|------|------------|
| Growth Team | [growth-team.md](./growth-team.md) — Conversion funnels, journey analytics |
| RevOps Analyst | [revops-analyst.md](./revops-analyst.md) — Dashboards, KPIs, self-service queries |
| RevOps Engineer | [revops-engineer.md](./revops-engineer.md) — Tool configuration, integrations |
| Data Engineer | [data-engineer.md](./data-engineer.md) — Schema, ETL, data quality |
| RevTech Specialist | [revtech-specialist.md](./revtech-specialist.md) — Third-party systems |
| Finance & Accounting | [finance-accounting.md](./finance-accounting.md) — Compliance, audit, close |

Don't see your role? Start with [RevOps Analyst](./revops-analyst.md)—it has the broadest coverage of common tasks.
