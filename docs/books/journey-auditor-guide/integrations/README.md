# Integrations

The systems we talk to—and how we stay in sync.

Billing data doesn't live in isolation. It flows between Lago for recurring billing, HubSpot for CRM, revenue recognition systems, accounting software, and more. Each integration introduces a reconciliation boundary: a place where our data meets external data and must match.

Start with [Recurring Billing (Lago)](./recurring-billing.md)—it's the core billing engine and the most critical integration. The CRM integration covers deal attribution and customer data sync. The remaining chapters document other systems as they're integrated.

**Integration health checklist:**
1. Can you reconcile internal events to Lago usage events?
2. Do customer records match between systems?
3. Are sync failures detected and alerted?
4. Can you identify and explain any discrepancies?

Each chapter covers the data flow, the reconciliation queries, and the common issues you might encounter.
