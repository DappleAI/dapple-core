# Monitoring

Trust but verify—finding problems before they find you.

This section covers the queries and checks that prove your billing data is correct. Operational integrity means nothing if you can't demonstrate it. These chapters give you the tools to verify consistency, catch anomalies early, and prepare for audits with confidence.

Start with [Data Audits](./data-audits.md) for routine checks you should run regularly. Move to [Data Reconciliation](./data-reconciliation.md) when you need to verify that internal records match external systems. Sandboxing covers test environments where you can validate changes safely.

**When to use each chapter:**
- **Daily operations:** Data Audits — Catch problems while they're small
- **Month-end close:** Data Reconciliation — Prove consistency before finalizing
- **Testing changes:** Sandboxing — Validate in isolation before production

The goal is boring month-ends. These chapters help you get there.
