# Templates

Copy, paste, adapt—queries for every occasion.

This section is your toolkit. Instead of writing queries from scratch, start with these battle-tested templates and adapt them to your specific needs. Each template includes the query, explains what it does, and notes common modifications.

**By purpose:**
- [Audit Queries](./audit-queries.md) — Data integrity checks you should run regularly
- [Reconciliation Queries](./reconciliation-queries.md) — Verify internal and external systems match
- [Integration Points](./integration-points.md) — Check health of system boundaries

**Reference material:**
- [Schema Reference](./schema-reference.md) — Table structures and relationships
- [KPI Definitions](./kpi-definitions.md) — Standard metrics and how to calculate them

**How to use these templates:**
1. Find a template that matches your goal
2. Read the description to confirm it's what you need
3. Copy the query
4. Modify the date ranges, filters, or groupings as needed
5. Run it and verify the results make sense

If you find yourself writing a query that others might need, consider contributing it back to this section.
